AI Toolkit
AI Toolkit brings a set of everyday AI tools into one web app, powered by Google Gemini.

Open AI Toolkit · Releases · Report an issue

Current release: v1.1.1
Tools
- Text Summarizer — Shorten articles, documents, and notes.
- Code Explainer — Get a clear explanation of code.
- Creative Writer — Work on stories, poems, and other writing.
- Translator — Translate text between languages.
- Grammar Checker — Fix grammar and improve wording.
- Idea Brainstormer — Develop ideas and explore options.
- Tech Interviewer — Practise technical interviews.
- Email Composer — Draft emails and formal messages.
- Research Assistant — Research a topic and bring information together.
- Logic & Math Solver — Work through maths and logic problems.
- Resume & Cover Letter — Draft or improve application documents.
Getting started
1. Open AI Toolkit.
2. Choose a tool from the sidebar.
3. Enter your text or question and run it.
The default API is available without adding your own key. To use your personal Gemini API quota, add a Gemini API key in Settings.
