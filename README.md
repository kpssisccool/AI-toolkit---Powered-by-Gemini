## A tool for the task at hand

AI Toolkit brings a range of everyday AI tasks into a single, straightforward workspace. Whether you're working through a piece of code, polishing a message, exploring a topic, or practising for an interview, there's a dedicated tool to start with.

## Explore the toolkit

| Category | Tools |
|---|---|
| **Writing & communication** | Creative Writer · Grammar Checker · Email Composer · Resume & Cover Letter |
| **Code & interviews** | Code Explainer · Tech Interviewer |
| **Research & problem-solving** | Research Assistant · Logic & Math Solver · Text Summarizer · Idea Brainstormer |
| **Languages** | Translator |

A little more about each one:

- **Text Summarizer** — Condense long articles, documents, and notes.
- **Code Explainer** — Make unfamiliar code easier to follow with clear explanations.
- **Creative Writer** — Develop stories, poems, outlines, and other written ideas.
- **Translator** — Translate text between languages, with automatic detection and language selection.
- **Grammar Checker** — Correct grammar and improve clarity and sentence flow.
- **Idea Brainstormer** — Find starting points for projects, concepts, and new ideas.
- **Tech Interviewer** — Practise technical interviews for software roles and technology stacks.
- **Email Composer** — Draft emails, replies, pitches, and formal requests.
- **Research Assistant** — Explore a topic and bring together research with source awareness.
- **Logic & Math Solver** — Work through maths questions, logic puzzles, and reasoning problems.
- **Resume & Cover Letter** — Write and refine resumes, achievement statements, and cover letters.

## Start in seconds

1. [Open AI Toolkit](https://aitoolkit.ai.studio/).
2. Choose a tool from the sidebar.
3. Enter your prompt and run it.

The default API is ready to use; you don't need to provide a key to get started. To use your own Gemini API quota, add a personal API key in **Settings**.

Useful links:

- [Get a Gemini API key](https://aistudio.google.com/app/apikey)
- [Gemini API documentation](https://ai.google.dev/gemini-api/docs)
- [Gemini API pricing](https://ai.google.dev/gemini-api/docs/pricing)
- [Gemini API terms](https://ai.google.dev/gemini-api/terms)
